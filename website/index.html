它有什么

都是实际会用上的东西，没有凑数的按钮。

樱花穿透

内置 frpc，填密钥和隧道 ID 就能把房间开到公网。记住凭证、检查本地端口。

整合包直装

把 .mrpack 里要联网下载的文件提前下好、校验 SHA1，产出一个完全离线的包。

导出实例

把装好的实例连同 mods、config 打成 .mrpack，发给朋友直接导入。

存档备份

一键备份到 saves-backup，只保留最近 5 份，随时可以回到三天前。

崩溃诊断

把 crash-report 翻成人话：Java 版本、内存、Mixin 冲突，逐条给出建议。

简单开服

下载官方服务端、自动写 eula、后台运行并显示控制台输出。

启动前自检

路径、Java、同 id 多版本模组、备份情况，启动前一次查完。

资源库

光影与资源包放进目录就能一键部署到任意实例。

常见问题

正版登录需要什么？

需要微软账号。启动器已内置客户端 ID，点「正版登录」按提示输入设备码即可。

联机怎么用？

主机开房间（或开服），点标题栏「节点」图标填樱花密钥与隧道 ID；朋友拿到地址后添加服务器。

下载很慢？

设置 → 下载 → 下载源改成镜像（BMCLAPI）。官方源对单连接限速约 0.5 MB/s。

游戏崩溃了？

先看「崩溃诊断」，再看「日志翻译」。两个都找不到原因，把错误报告发给作者。
